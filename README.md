# Финальный проект "Платформа для отслеживания и симуляции торговли валютами"
# ValutaTrade Hub

Комплексная платформа для отслеживания и симуляции торговли валютами. 
Проект реализован в виде консольного приложения и состоит из двух микросервисов:
1. **Core Service** — управление пользователями, портфелями, транзакциями (покупка/продажа).
2. **Parser Service** — сбор актуальных курсов с внешних API (CoinGecko, ExchangeRate-API).

В проекте реализована упрощённая модель торговли (согласно условиям задания):

Покупка (buy): увеличивает баланс покупаемой валюты. USD не списывается.

Продажа (sell): уменьшает баланс продаваемой валюты. Выручка в USD не зачисляется.

Оценка стоимости: при покупке/продаже в консоль выводится оценочная стоимость операции в USD по текущему курсу.

Пароли хранятся в виде хешей (PBKDF2 с солью), ключи API — в переменных окружения.

Все действия записываются в logs/actions.log.

## Запуск программы

### 1. Требования
* Python 3.14+
* Менеджер пакетов uv

### 2. Установка зависимостей
```bash
uv sync
```

### 3. Настройка окружения (API ключи)

Проект использует API для получения курсов валют.

Создайте файл .env в корне проекта (или скопируйте .env.example):

```bash
cp .env.example .env
```
Откройте .env и добавьте ваш ключ от ExchangeRate-API:
```bash
EXCHANGERATE_API_KEY=ваш_ключ_сюда
```
Если ключ не указан, парсер будет использовать тестовые данные.

### 4. Запуск Core Service (CLI)

```bash
uv run project
```

### 5. Запуск Parser Service (Планировщик)

Для автоматического обновления курсов каждые 5 минут запустите планировщик в отдельном терминале:

```bash
uv run python -m valutatrade_hub.parser_service.scheduler
```

### 6. Доступные команды CLI

После запуска uv run project доступны следующие команды:
```bash
Команда	              Описание
register --username <name> --password <pass>	Регистрация нового пользователя
login --username <name> --password <pass>	Вход в систему
show-portfolio [--base <currency>]	Показать портфель (по умолчанию в USD)
buy --currency <code> --amount <number>	Купить валюту
sell --currency <code> --amount <number>	Продать валюту
get-rate --from <code> --to <code>	Узнать курс между двумя валютами
update-rates [--source <coingecko/exchangerate>]	Обновить курсы вручную
show-rates [--currency <code>] [--top <N>] [--base <code>]	Показать курсы из кэша
help	Показать справку
exit	Выйти из программы
```
Пример работы:

```bash
Введите команду: register --username alice --password 1234
Введите команду: login --username alice --password 1234
Введите команду: buy --currency BTC --amount 0.1
Введите команду: show-portfolio
```
